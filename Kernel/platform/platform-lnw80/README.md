# Fuzix for the LNW80-II or LNW80 with CP/M mod

## Supported Hardware

- LNW80-II / LNW80-I with CP/M mod
- Hard disk interface (or compatible modern retro such as the FreHD)

## Options

- Floppy disk (pretty basic)
- RTC at 0xB0
- Alpha Products style Joystick

## Unsupported
- Graphics
- Apple style joystick port

## Installation

make diskimage will build a TRS80 disk image for a FreHD or emulator, along
with a boot disk in .jv3 format. These can be turned into real disks using
the FreHD.
